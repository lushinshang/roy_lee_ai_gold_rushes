## 200字介紹

Cluely共同創辦人Roy Lee在Jack Neel Podcast上，提出一套具體到近乎機械化的「六個月內用AI影片賺到一百萬美元」操作步驟：找一套AI影片工具、找一百家剛拿到創投的軟體公司、免費做廣告、談抽成、重複十六次。他也描述了自己公司只用兩名全職工程師維護七個年營收破百萬美元的產品，並靠上千名創作者以廣告成效抽成的方式合作。這篇導讀整理他講的三個AI淘金機會與具體打法，同時附上一個必要的信任度但書：Roy Lee本人在2026年3月公開承認曾造假營收數字（原宣稱700萬美元ARR，實際約520萬美元），這件事會直接影響你該怎麼看待他自述的其他數字。文章也收錄他自己拆解的限制——行銷是零和賽局，這套打法能成立正是因為現在願意動手做的人還不夠多。
